# Smart Commercial Calculator & GST Checker

A menu-driven C console application for performing basic arithmetic operations and calculating standard 18% GST.

## Features
- **Basic Arithmetic:** Addition (`+`), Subtraction (`-`), Multiplication (`*`), and Division (`/`) with division-by-zero validation.
- **18% GST Calculator:** Calculates 18% GST tax and generates an itemized final payable invoice breakdown with negative-price validation.
- **Continuous Menu Loop:** Runs in a `while(1)` loop until the user chooses to exit.
